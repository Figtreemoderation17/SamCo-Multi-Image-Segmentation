## 🔍 How the Software Works

This tool uses deep learning technology to understand images. It uses two primary models:

*   DINOv2: This model learns the shapes and textures of objects in photos. It helps the software recognize the same object even if the angle or lighting changes.
*   SAM: The Segment Anything Model creates precise outlines around objects. It provides the final cut-out images.

By combining these two models, the software maintains consistency across multiple photos. This leads to better results than working on each image by hand.

## 🛠️ Troubleshooting

If you encounter issues while using the software, check these common items:

*   Check your internet connection if the program stops during the first run. It needs to download additional files from the internet for the AI models.
*   Ensure your graphics card drivers are current. Outdated drivers often cause problems with AI software.
*   Verify that your antivirus software does not block the application. You might need to add an exception for this folder.
*   Ensure you have enough space on your C: drive. The software caches temporary image data while it processes your requests.

If the program closes unexpectedly, restart your computer and try again. If the issue remains, check the terminal window for error messages. These messages often explain why the software stopped.
